# 🔦 공포 술래잡기

불 끄고, 각자 폰 들고 하는 실시간 공포 술래잡기. 술래는 안대를 쓰고, 도망자는 폰 마이크로
술래와의 거리를 "위험도"로 느끼면서 도망 다닙니다. 스킬로 서로 방해하거나 도와줄 수 있어요.

## 준비물

- 다같이 접속할 노트북/PC 1대 (서버 역할)
- 참가자 전원의 스마트폰 (같은 와이파이에 연결)
- 안대 1개, 불 끌 수 있는 방

## 실행 방법

```bash
npm install
npm start
```

터미널에 아래처럼 접속 주소가 뜹니다.

```
https://192.168.x.x:8443
```

이 주소를 참가자들 폰 브라우저에 입력해서 접속하세요 (같은 와이파이 필수).

### ⚠️ "안전하지 않음" 경고가 뜨는 이유

마이크 접근은 브라우저 보안 정책상 HTTPS가 필요해서, 서버가 자체 서명(self-signed)
인증서를 자동 생성합니다. 공인 인증서가 아니라서 처음 접속하면 경고가 뜨는데, 아래처럼
진행하면 됩니다.

- **크롬(안드로이드)**: "고급" → "...(안전하지 않음)으로 이동"
- **사파리(iOS)**: "자세히 보기" → "이 웹 사이트 방문"

## 게임 흐름

1. **방 만들기 / 참가하기**: 방장이 방을 만들면 4자리 코드가 나옵니다. 나머지는 그 코드로 참가.
2. **로비**: 방장이 게임 시간(3~20분)과 마이크 민감도를 설정하고 시작.
3. **역할 배정 + 튜토리얼**: 무작위로 1명이 술래, 나머지는 도망자. 역할별 스킬 설명 화면이 뜹니다.
   - 이 화면에서 "이해했어요" 버튼을 누를 때 마이크 권한(도망자) / 동작 센서 권한(술래, iOS)을
     요청하니 반드시 허용해주세요.
4. **주변 소음 측정(캘리브레이션)**: 다같이 조용히 4초 정도 대기. 이때 각 도망자 폰이 "조용한 상태"를
     기준값으로 저장합니다.
5. **카운트다운**: "불 끄세요!" 신호와 함께 5초 카운트다운.
6. **본게임**: 술래는 안대 착용 후 실제로 돌아다니며 사람을 찾고, 도망자는 폰의 위험도 게이지를
   보며 도망 다닙니다.
7. **잡기**: 술래가 실제로 누군가를 붙잡으면(또는 잡았다고 느끼면) **폰을 흔듭니다** → 모든
   도망자 폰에 은은한 진동이 갑니다. 실제로 붙잡힌 사람이 자기 폰에서 **"저 잡혔어요"** 버튼을
   눌러 스스로 인정합니다 (술래가 안대를 써서 화면을 볼 수 없기 때문에 자율 판정 방식입니다).
8. **종료**: 모든 도망자가 잡히면 술래 승리, 제한시간까지 1명이라도 살아남으면 도망자 승리.
9. 결과 화면에서 방장이 "로비로 돌아가기"를 누르면 같은 인원으로 재시작할 수 있습니다.

## 위험도(술래와의 거리)는 어떻게 계산되나요?

술래 폰이 낮은 심장박동 같은 소리를 게임 내내 반복 재생합니다. 각 도망자 폰은 마이크로 그 소리가
얼마나 크게 들리는지 실시간으로 측정해서 "가까울수록 위험도 상승"으로 변환합니다.

**정확한 GPS/거리 측정이 아니라 마이크 볼륨 기반 근사치**라서 실제 체감과 다소 오차가 있을 수
있어요. 아래를 참고하면 더 잘 동작합니다.

- 게임 시작 전 **미디어 볼륨을 충분히 올려두세요** (스킬 효과음/술래 비콘음이 잘 들려야 재미있어요).
- 너무 시끄러운 방보다는 어느 정도 조용한 방에서 더 잘 맞습니다 (음악은 끄는 걸 추천).
- 로비의 "마이크 민감도" 슬라이더로 미리 조정하거나, 한 판 해보고 너무 안 오르면/너무 빨리
  차면 다음 판에 조정하세요.
- 도망자 폰의 화면 밝기를 너무 밝게 하지 마세요. 어두운 방에서 화면 빛이 새어나가면 위치가
  들킬 수 있어요.

## 스킬

### 도망자

| 스킬 | 발동 조건 | 효과 |
|---|---|---|
| 💨 연막탄 | 위험도 70 이상, 2회 | 나 말고 무작위의 다른 도망자 폰에서 2초간 큰 소리가 남 (술래 청각 교란) |
| 🫧 숨죽이기 | 언제든, 1회 | 8초간 무적(잡히지 않음) + 위험도 게이지 고정. 지속 중엔 다른 스킬 사용 불가 |
| 📳 경고 펄스 | 45초마다, 무제한 | 나를 포함한 모든 도망자 폰에 짧은 진동 경고 (위치정보 없음) |
| 🫀 심박 안정 | 언제든, 1회 | 15초간 위험도 상승 폭 절반으로 감소 |

### 술래

| 스킬 | 발동 조건 | 효과 |
|---|---|---|
| 👹 괴성 | 게임당 1회 | 모든 도망자 폰에서 동시에 큰 비명 소리 발생 |

잡기 시도는 스킬이 아니라 **폰 흔들기**로 합니다 (술래는 안대 때문에 화면 버튼을 못 보므로).
흔들기가 잘 인식 안 되면 화면의 "잡기 시도(흔들기 대체)" 버튼을 눌러도 됩니다.

## ⚠️ 안전 수칙 (게임 내 튜토리얼 화면에도 표시됩니다)

- 시작 전 방 안의 부딪힐 물건, 날카로운 모서리, 계단 등을 미리 치우거나 확인하세요.
- 술래는 절대 뛰지 말고 천천히 걸으세요. 도망자도 급하게 뛰지 마세요.
- 다치거나 무섭거나 불편하면 언제든 "그만!"을 외쳐서 게임을 멈추세요.

## 알려진 한계

- 마이크 기반 위험도는 **근사치**입니다. 방 구조, 사람들 소음, 폰 마이크 성능에 따라 오차가 있을 수
  있습니다. 정밀한 거리 측정이 아니라 "대략 가까워지면 오른다" 정도로 즐겨주세요.
- Web Bluetooth/GPS 대신 오디오(마이크) 방식을 택한 이유는 iOS/Android 브라우저에서 별도 설치 없이
  가장 안정적으로 동작하기 때문입니다.
- 같은 와이파이가 아니면 접속이 안 됩니다 (같은 네트워크 대역이어야 함).
- 방 정보는 서버 메모리에만 저장되므로, 서버(호스트 노트북)를 끄면 진행 중이던 방 정보가 사라집니다.

## 프로젝트 구조

```
server/
  index.js     - Express + Socket.IO 서버, 이벤트 처리
  game.js      - 방/게임 상태 관리
  skills.js    - 서버 권위 스킬 정의 (충전량/쿨다운/효과)
  gen-cert.js  - 로컬 HTTPS용 자체 서명 인증서 생성
public/
  index.html   - 전체 화면(로비/튜토리얼/캘리브레이션/게임/결과)
  css/style.css
  js/skills.js - 클라이언트 표시용 스킬 텍스트
  js/audio.js  - 비콘 재생, 마이크 분석, 효과음 합성, 진동, 흔들기 감지
  js/app.js    - 클라이언트 상태 머신 및 소켓 이벤트 처리
```
